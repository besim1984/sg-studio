Privacy policy

SG Studio · last updated 19 November 2026

SG Studio is a desktop application used by one person, the owner of the YouTube channel it connects to. It has no server and no user accounts of its own.

What the application accesses

After the owner signs in with Google and allows it, the application uses the YouTube Data API and the YouTube Analytics API to read the connected channel's details, video list, view and watch-time statistics and estimated revenue. If the owner also allows uploads, the application uploads a video and its thumbnail to that channel, and only when the owner starts the upload.

Where the data is kept

All data stays on the owner's own computer. Google sign-in tokens are stored encrypted with the operating system's secure storage. Nothing is sent to the developer or to any other server, except the requests made directly to Google's APIs.

Sharing

The application does not sell, share or transfer any data to third parties, and does not use it for advertising.

Removing access

The owner can disconnect the channel in the application, which deletes the stored sign-in, or remove the application's access at any time at myaccount.google.com/permissions. Deleting the application's folder removes all stored data.

Google and YouTube

The application uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy: open an issue in this site's GitHub repository.
